# DeepCSCN

**DeepCSCN** is an R package for inferring cell-type- and cell-state-specific gene co-expression modules from single-cell RNA sequencing (scRNA-seq) and spatial transcriptomics data. It combines gene representation learning with module identification and cell-type-specificity assessment.

DeepCSCN infers **undirected gene co-expression associations**; it is not a method for inferring directed gene regulatory networks. When applied to spatial transcriptomics data, it uses gene expression profiles without incorporating spatial coordinates or neighborhood information.

## Implementation

The DeepCSCN workflow is operated from R. Its **GeneCluster** representation model, including the CNN–SPP encoder and cluster-guided training procedure, is implemented in Python using PyTorch. The Python backend is bundled with the R package at `inst/python/deepcscn_backend.py` and is called directly from R through `reticulate`.

Users do not need to modify Python scripts or specify a separate GeneCluster repository. The backend supports `device = "auto"`, `"cpu"`, `"cuda"`, and explicit CUDA devices such as `"cuda:1"`. It does not use hard-coded GPU indices or absolute input/output paths.

**Input preprocessing is explicit:** `run_genecluster()` uses the expression values supplied by the user and does not automatically apply counts-per-10,000 (CP10K) normalization or `log1p` transformation.

## Installation and reproducible environments

Run the commands below from the root directory of the DeepCSCN repository.

### Complete installation for new users (CPU)

1. Confirm that Conda and the download tool are available:

```bash
conda --version
curl --version
```

If `conda` is unavailable, install Miniconda or Anaconda before continuing.

2. Create a working directory and download the v0.2.0 source package from the
   GitHub Release:

```bash
mkdir -p deepcscn_install
cd deepcscn_install

curl -L -o DeepCSCN_0.2.0.tar.gz \
  https://github.com/Byting820/DeepCSCN/releases/download/v0.2.0/DeepCSCN_0.2.0.tar.gz
```

3. Verify that the download is complete and unchanged:

```bash
echo "f38e4e7331a17b46af9152d6862550a55662268fee60c51b9ee04a6f521dd855  DeepCSCN_0.2.0.tar.gz" \
  | sha256sum --check -
```

The expected output is `DeepCSCN_0.2.0.tar.gz: OK`. On macOS, calculate the
checksum with `shasum -a 256 DeepCSCN_0.2.0.tar.gz` and compare it with the
value above.

4. Extract the source package and enter its directory:

```bash
tar -xzf DeepCSCN_0.2.0.tar.gz
cd DeepCSCN
```

5. Create and activate the reference CPU environment:

```bash
conda env create -f environment.yml
conda activate deepcscn
```

6. Ensure that `reticulate` uses the Python interpreter from this environment,
   then install the R package:

```bash
export RETICULATE_PYTHON="$CONDA_PREFIX/bin/python"
R CMD INSTALL .
```

A successful installation ends with `* DONE (DeepCSCN)`.

7. Verify the installed R package and bundled Python backend:

```bash
Rscript -e 'library(DeepCSCN); cat("DeepCSCN", as.character(packageVersion("DeepCSCN")), "\n"); print(check_deepcscn_python())'
Rscript reproducibility/verify_environment.R
```

The first command should report DeepCSCN version `0.2.0` and list the active
Python, PyTorch, NumPy, pandas, and scikit-learn versions.

8. Run the end-to-end, one-epoch CPU smoke test:

```bash
Rscript reproducibility/smoke_test.R
```

The final line should be:

```text
R-to-Python smoke test passed.
```


### NVIDIA GPU environment

For GPU acceleration, `environment-gpu.yml` specifies PyTorch 2.2.2 with CUDA 12.1:

```bash
conda env create -f environment-gpu.yml
conda activate deepcscn-gpu
R CMD INSTALL .
Rscript reproducibility/verify_environment.R
```

Build and run the CPU container:

```bash
docker build -t deepcscn:0.2.0 .
docker run --rm -it -v "$PWD/work:/work" deepcscn:0.2.0
```

```bash

docker run --rm -it --gpus all -v "$PWD/work:/work" deepcscn:0.2.0-gpu
```

## Input data

The main analysis uses the following inputs:

| Input | Description |
| --- | --- |
| `expression` | Numeric gene-by-cell expression matrix, with genes in rows and cells in columns. |
| `feat` | Gene-by-feature representation matrix generated by GeneCluster. |
| `meta` | Cell annotations, with row names matching the expression matrix's column names. |
| `marker` | Marker-gene information for the cell types or states of interest. |

**Cell-order considerations.** The CNN encoder is sensitive to the order of cells in the input matrix. DeepCSCN preserves the supplied order and records it with the model checkpoint; it does not infer a biologically meaningful cell order. For reproducibility, use a consistent and documented ordering across runs.

## Example workflow

The following example illustrates preprocessing, GeneCluster training, and identification of developmental-stage-specific modules from an hESC dataset. Update the input and output paths to match your project.

### 1. Configure Python and load the input data

```r
library(DeepCSCN)

# Configure Python before the first function that uses reticulate.
configure_deepcscn_python(condaenv = "deepcscn")
check_deepcscn_python()

expression_path <- "path/to/expression.csv.gz"
metadata_path <- "path/to/metadata.csv"
target_state <- "00h"  # Replace with a value present in meta$time_info.
results_dir <- "results"
dir.create(results_dir, recursive = TRUE, showWarnings = FALSE)

expression <- read.csv(expression_path, row.names = 1, check.names = FALSE)
expression <- as.matrix(expression)
storage.mode(expression) <- "double"
meta <- read.csv(metadata_path, row.names = 1, check.names = FALSE)

stopifnot(
  !anyDuplicated(rownames(expression)),
  !anyDuplicated(colnames(expression)),
  !anyDuplicated(rownames(meta)),
  "time_info" %in% colnames(meta),
  all(rownames(meta) %in% colnames(expression)),
  target_state %in% meta$time_info,
  all(is.finite(expression)),
  all(expression >= 0)
)

# Use the metadata order consistently throughout the analysis.
expression <- expression[, rownames(meta), drop = FALSE]
```

If the GPU Conda environment is being used, replace `deepcscn` with
`deepcscn-gpu`. Python must be selected before calling `findHVG_py()`,
`check_deepcscn_python()`, or `run_genecluster()` in the R session.

### 2. Filter genes and select highly variable genes

```r
plot_data <- data.frame(mean = rowMeans(expression))
density_result <- expr_density_plot(plot_data)
print(density_result$plot)

filtered_expression <- filter_expr(
  expression,
  metadata_path,
  cutoff = round(density_result$peak_x, 2)
)

n_hvg <- min(1000L, nrow(filtered_expression))
hvg <- findHVG_py(filtered_expression, num_HVG = n_hvg)
stopifnot(nrow(hvg) > 15L, identical(colnames(hvg), rownames(meta)))
```

Scanpy is included in the supplied Conda environments. If the input has
already been normalized or log-transformed, replace this preprocessing block
with the preprocessing appropriate for that data and pass the resulting
gene-by-cell matrix to `run_genecluster()`.

### 3. Train GeneCluster from R

```r
fit <- run_genecluster(
  expression = hvg,
  output_dir = file.path(results_dir, "genecluster_seed0"),
  n_clusters = 15,
  epochs = 100,
  batch_size = 32,
  learning_rate = 0.01,
  focal_gamma = 2,
  seed = 0,
  device = "auto"
)

feat <- fit$features
head(fit$clusters)
plot(fit$history$epoch, fit$history$loss, type = "l")
```

Each training directory contains the input matrix, learned feature matrix, pseudo-cluster assignments, epoch-level training history, PyTorch checkpoint, and `run_metadata.json`. The metadata records training parameters, dependency versions, resolved compute device, and the SHA-256 checksum of the input matrix.

The 100-epoch analysis may take substantial time. Use the installation smoke
test shown earlier to verify the software before starting this run. A repeated
call with the same output directory requires `overwrite = TRUE` or a new
output directory.

### 4. Identify cell-type- or state-specific modules

```r
marker_path <- file.path(results_dir, "markers.csv")
markers <- marker_identify(expression, metadata_path, marker_path)
DEG <- markers[markers$gene %in% rownames(hvg), , drop = FALSE]
DEG <- DEG[!duplicated(DEG$gene), , drop = FALSE]
if (!nrow(DEG)) {
  stop("No marker genes overlap the selected HVGs.")
}

CelltypeFeat(DEG, feat, hvg, meta, "time_info")

# CelltypeFeat currently writes one file per state under data/res/feat/.
target_feature_path <- file.path(
  "data", "res", "feat", paste0(target_state, "_feat.csv")
)
stopifnot(file.exists(target_feature_path))
target_features <- read.csv(
  target_feature_path,
  row.names = 1,
  check.names = FALSE
)

first_result <- FirstCluster(target_features)
gene_correlation <- first_result$celltype_cor
initial_clusters <- first_result$celltype_cluster

score_result <- CellTypeSpecificScore(
  hvg,
  meta,
  initial_clusters,
  target_state
)
print(score_result)

# Select the initial cluster with the higher target-state specificity score.
score_values <- c(score_result$M1_score, score_result$M2_score)
if (any(!is.finite(score_values))) {
  stop("The specificity scores are not finite; check zero-sum genes and metadata.")
}
selected_cluster_id <- which.max(score_values)
specific_module <- initial_clusters[
  initial_clusters$cluster == selected_cluster_id,
  ,
  drop = FALSE
]
if (nrow(specific_module) < 4L) {
  stop("The selected initial cluster is too small for finer clustering.")
}

specific_correlation <- gene_correlation[
  rownames(specific_module),
  rownames(specific_module),
  drop = FALSE
]
min_module_size <- min(50L, max(2L, nrow(specific_module) %/% 2L))
specific_cluster_result <- specific_cluster(
  specific_correlation,
  minClusterSize = min_module_size
)

# dynamicTreeCut uses cluster 0 for unassigned genes; exclude it from GO.
assigned_modules <- specific_cluster_result[
  specific_cluster_result$cluster > 0,
  ,
  drop = FALSE
]

write.csv(
  assigned_modules,
  file.path(results_dir, paste0(target_state, "_modules.csv"))
)
```

The initial clustering step separates candidate gene groups. The target-cell-type specificity score is then used to identify the relevant group before finer module detection. **The cluster label itself has no fixed biological meaning**; select the group according to its score.

## Main R functions

| Function | Purpose |
| --- | --- |
| `run_genecluster()` | Train the bundled PyTorch CNN–SPP model with cluster-guided learning. |
| `configure_deepcscn_python()` | Configure the Python environment used through `reticulate`. |
| `check_deepcscn_python()` | Inspect the active Python and PyTorch configuration. |
| `CelltypeFeat()` | Extract gene features associated with a cell type or developmental state. |
| `CellTypeSpecificScore()` | Calculate module specificity scores to guide module selection. |
| `FirstCluster()` | Identify initial gene clusters. |
| `specific_cluster()` | Perform finer clustering within a selected gene group. |
| `Run_GO()` | Perform Gene Ontology enrichment analysis. |

## Reproducibility and limitations

DeepCSCN sets random seeds for R, Python, NumPy, scikit-learn, and PyTorch and requests deterministic PyTorch operations. To reduce variability from parallel numerical reductions, deterministic runs also restrict numerical-library threading to one thread. Nevertheless, bitwise-identical results across machines are not guaranteed: CPU instruction sets, GPU hardware, NVIDIA drivers, and numerical-library implementations may affect floating-point computations and downstream pseudo-label assignments.

The `run_metadata.json` file records the relevant software versions, hardware-facing settings, and input checksum to support verification and troubleshooting. Users should also preserve the input expression matrix, its cell ordering, and preprocessing choices when reproducing analyses.
